Cara Mengaktifkan Kode Baru di Apps Script

Langkah Memperbarui Versi Deployment:

  1. Buka editor Google Apps Script di browser Anda.
  2. Pastikan isi file Code.gs sudah diperbarui dengan kode terbaru, lalu klik ikon Simpan (Disket).
  3. Klik menu tombol biru Terapkan (Deploy) di pojok kanan atas.
  4. Pilih Kelola penerapan (Manage deployments).
  5. Klik ikon Pensil (Edit) pada penerapan aktif Anda.
  6. Pada opsi Versi (Version), ubah dropdown menjadi: Versi baru (New version).
  7. Klik tombol biru Terapkan (Deploy).
